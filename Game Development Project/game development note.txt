- Background images & repeat images 
imported background image with sky, building, Platform. instead of stretching the image, i used wrap mode for inifinite scrolling, however there was an issue with setting those so it took long time to figure it out. 

created 3d object in 2d, set the background images to texture type to sprite, sprite mode multiple, mesh type : tight, wrap mode to 'REPEAT'. Once material is created, it is important to choose the right shader. in this case, i chose LIT, then expanded tiling from more than 1.



- script for background images 

created mono behavior script - 'backgroundscroll' (C#). Applied to all 3 background images.
I want to give different speeds for each backgrounds. (sky, building, Platform)

meshRenderer.material.mainTextureOffset += new Vector2(scrollSpeed * Time.deltaTime, 0);

(speed × time = distance. scrollSpeed is how fast, Time.deltaTime is how much time just passed (one tiny frame's worth), and multiplying them tells you how far to move right now. It keeps the scroll speed the same no matter how fast or slow the computer runs the game.)
